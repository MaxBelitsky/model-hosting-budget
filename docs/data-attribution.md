# Data Attribution Policy

This repository contains original Apache-2.0 code and synthetic example data.

Do not commit model weights, benchmark datasets, private workloads, credentials, provider account material, bulk upstream metadata, or copied historical reports. Public model or provider facts may be represented only as minimal normalized fields needed for a reviewed profile, with provenance and redistribution terms recorded by the contributor.

Adding a non-synthetic profile requires:

- A pinned source or reproducible observation reference.
- A license or terms note for any upstream material.
- A hand-calculated fixture or observation-backed test.
- No vendored copyrighted datasets or provider pages.
